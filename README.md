# Domestique

Fork of [gopro-dashboard-overlay](https://github.com/time4tea/gopro-dashboard-overlay), focused on cycling.

## Build

**Windows** (PowerShell):
```powershell
.\packaging\build.ps1
```

**macOS:**
```bash
./packaging/build.sh
```

Both produce `dist/Domestique-portable.zip`. Unzip it and run `gopro-dashboard-gui` (`.exe` on Windows).
